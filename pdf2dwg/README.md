# PDF → DWG Converter (Windows)

Настольное приложение для перевода векторных PDF-чертежей в **DWG** / **DXF**.

## Скачать готовый exe
GitHub → вкладка **Actions** → workflow **Build PDF2DWG exe** → последний успешный запуск →
артефакт **PDF2DWG-windows** (внутри `PDF2DWG.exe`, установка не нужна).
Для релиза: создать тег `pdf2dwg-v1.0.0` — exe появится в **Releases**.

## Возможности
- выбор файлов, целой папки (с подпапками) или drag & drop в окно;
- папка вывода: рядом с PDF или любая другая (кнопка «Обзор…»);
- формат DWG (AutoCAD 2000…2018) или DXF;
- масштаб 1:N — координаты в мм, при 1:100 получаются реальные размеры;
- выбор страниц (`1-3, 5, 8-`), режим «файл на страницу» или «все листы в один файл»;
- переносится: линии/полилинии, кривые (дуги, окружности), заливки → HATCH,
  текст → TEXT (с поворотом), цвет, толщина линий, слои по цвету, растровые картинки (опц.);
- светлая/тёмная тема, настройки запоминаются.

## Про DWG
Формат DWG закрытый, бесплатной библиотеки для его записи нет. Программа создаёт DXF
и конвертирует его в DWG бесплатным **ODA File Converter**
(https://www.opendesign.com/guestfiles/oda_file_converter). Установите его один раз —
приложение найдёт его само (или укажите путь вручную). Без него доступен DXF,
который открывают AutoCAD, Revit, nanoCAD, BricsCAD и др.

## Ограничения
- Сканы (растровые PDF) векторов не содержат — их можно вставить только картинкой-подложкой.
- Кривые Безье аппроксимируются полилиниями (ползунок «Гладкость дуг»).
- Штриховки из PDF приходят набором линий, размеры — линиями и текстом (не размерными объектами).

## Запуск из исходников / сборка вручную
```bat
cd pdf2dwg
pip install -r requirements.txt
python app.py
build.bat        :: -> dist\PDF2DWG.exe
```
